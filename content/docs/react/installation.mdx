## Use the offline file

Download [`release/calendar.html`](https://github.com/AKIBUZZAMAN-AKIB/my-calendar/blob/main/release/calendar.html) and open it in any modern browser. It needs no server and makes no network requests.

## Run from source

```bash
git clone https://github.com/AKIBUZZAMAN-AKIB/my-calendar.git
cd my-calendar
pnpm install
pnpm dev
```

> ✅ Visit the calendar at: `http://localhost:3000/calendar`

The page is `src/app/calendar/page.tsx`:

```tsx
import { Suspense } from "react";
import { Calendar } from "@/features/calendar/calendar";
import { CalendarSkeleton } from "@/features/calendar/skeletons/calendar-skeleton";

export default function CalendarPage() {
  return (
    <main className="h-dvh w-full overflow-hidden">
      <Suspense fallback={<CalendarSkeleton />}>
        <Calendar />
      </Suspense>
    </main>
  );
}
```

## Build the single HTML file

```bash
npm run build:single
```

This writes `dist/single.html`: Tailwind CSS, the Geist font and the bundled React app inlined into one minified file, with comments removed. See `scripts/build-single.mjs`.

## About the original registry

The original project can be added to another app from its shadcn registry with `npx shadcn@latest add "https://calendar.jeraidi.tech/r/full-calendar.json"`. That installs the upstream component, which does not include the changes in this repository (Subjects, the floating time picker, saved events and the phone layout).
